# 遊び方

人間1人とAI3人で東風戦を遊びます。対局画面には手牌、捨て牌、副露、ドラ、点数、本場、供託、残りの山を表示します。採用ルールは[ルール仕様](rules/riichi.md)を参照してください。

## 起動する

Linuxで、日本語を表示できる横幅92列以上の端末を使用します。初回の導入は[README](../README.md#端末で遊ぶ)、必要な開発環境と固定ツールの詳細は[導入手順](development/reproducibility.md#導入)を参照してください。

ツールを導入した後は、リポジトリのルートで実行します。

```sh
source dist/tools/activate.sh
cargo run --locked -p suzume-cli --release
```

色や画面消去を使わずに表示するには、次のように `--plain` を付けます。

```sh
cargo run --locked -p suzume-cli --release -- --plain --seed 42
```

標準入出力が端末でない場合や `NO_COLOR` を指定した場合も、色と画面消去を使いません。

## 牌を選ぶ・鳴く・和了する

行入力式です。操作を入力した後にEnterで確定してください。画面に表示される、現在選べる操作を使います。

| 入力 | 操作 |
|---|---|
| `1`〜`14` | 表示された手牌番号の牌を捨てる |
| `r 5` | 5番の牌を捨ててリーチする。成立条件を満たす場合のみ |
| `t` / `ron` | ツモ和了 / ロン和了 |
| `/1`、`/2`… | 表示された補助操作を選ぶ。複数のチーや槓も選び分けられる |
| `Enter` | 応答を見送る、局終了後に次局へ進む。打牌中は牌番号が必要 |
| `h` | 操作説明を表示する |
| `q` | 対局を中断する |

不正な入力では対局は進まず、入力を受け付け直します。手牌は種類順に並び、最後にツモった牌も別に表示します。リーチ後に捨てられるのはツモ牌だけです。

河の牌表記は、萬子が `m`、筒子が `p`、索子が `s`、字牌が `z` です。画面の「すずめ」は、このプロジェクトのゲーム名を示します。

## AIと配牌を設定する

端末の人間席と表示席は0、他の3席はAIです。設定ファイルを使う場合も、この組合せを指定します。

```sh
cargo run --locked -p suzume-cli --release -- --config config/default.toml
```

`--config` と `--seed` は併用できません。設定ファイルを使う場合は `game.seed` を変更します。配牌の乱数種を指定しない場合は0です。

AIの種類と予算は[AIの案内](ai/README.md)、設定項目は[共通設定](api/configuration.md)にまとめています。全員AIでの自動対局やログ保存は[AI設定と対局の記録](ai/cli.md)を参照してください。

## ルールの範囲

現行の対局では赤牌・加槓・リーチ後の槓・途中流局・流し満貫・天和/地和・包を採用しません。複数ロンは頭ハネ、喰い断あり、食い替えなしです。通信対戦はありません。

外部mjsonに記録された赤牌・加槓・複数ロンの解析は、対局の採用ルールとは別の機能です。対応範囲は[外部牌譜との互換性](logging/mjai-compatibility.md)に記載しています。
