# ADR-0005：感想戦・解析のための版付きJSON Lines

日付：2026-11-23。状態：採用。詳細な項目と限界はログ仕様で固定します。

## 背景

初版の`history`はメモリー上のRust値で、`events`は表示用の文字列です。表示文言の解析やDebugの保存では、型・版・意味・公開範囲が安定しません。`Game::apply`の全体cloneは累積履歴も複製し、長い対局の総複製量が二乗で増えます。

利用者は後日の感想戦、統計、AIエージェントの読解、将来の学習データ生成を求めています。

## 決定

UTF-8のJSON Linesを用い、ヘッダ、構造化された適用済み操作、末尾記録を1行ずつ読み書きします。日時や自然言語だけを機械判定の識別子にはしません。入力サイズ、1行長、連番、版、対応エンジン、終了/中断を検査します。途中で切れた入力を正常終了へ読み替えません。

| 形式 | 内容 | 用途と制限 |
|---|---|---|
| replay | 形式・エンジン・規則・shuffleの識別、完全なseed、構成、操作、照合情報 | 信頼するローカル分析用。全ての隠れた牌を再構築できる |
| public | 公開情報と公開された操作。seed、他家手牌、私的な手牌添字、内部状態のhashを除く | 共有・読解用。完全再生はできず、再生器は明示拒否する |

完全ログと共有ログを同じ型の可視性フラグだけで曖昧に扱いません。既存履歴は保持しつつ、操作候補の複製には累積履歴・表示記録を含めず、成功後だけ新しい記録を追記します。出力はBufRead/Writeの境界で、全JSONLをメモリーに組み立てることを必須にしません。

再生器は同じcoreへ操作を適用し、連番・合法性・末尾の一致を確認します。解析用変換は観測、行動ID、報酬、次の観測席を明示した遷移を出力します。表示文言を逆解析しません。

## 代替案と検査

一つの巨大なJSON配列は途中追記・行単位の解析が不便です。バイナリ形式は容量面で有利ですが、今回のAIエージェントや人による読解には追加の変換が必要です。JSONLを正本とし、圧縮は必要に応じた外側の処理とします。

全情報の再生一致、共有用への私的情報不在、改変、連番欠落・重複、未知項目、版違い、途中切断、過大行、I/O失敗を検査します。hashは改変の偶発的検出に使うもので、署名や対戦相手への真正性保証ではありません。
