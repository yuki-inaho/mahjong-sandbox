# 初版のリーチ麻雀規則

## 宣言の位置

機械可読の正本は `rules/riichi.rules` です。RustとLeanの定数をここから生成します。
生成された値と文章の意味が一致していることを、対応表・テスト・レビューで検査します。
定数の同期だけでは、文章で定義した麻雀全体が正しいことの証明にはなりません。

## 卓と進行

| 項目 | 採用規則 |
|---|---|
| 人数・牌 | 4人、34種類各4枚、合計136枚。赤牌なし |
| 初期持点 | 各25,000点、供託込み総額100,000点 |
| 対局 | 東風戦。親の和了または親テンパイで連荘。飛び終了あり |
| 山 | 王牌14枚。通常ツモから王牌を除外 |
| リーチ | 門前、テンパイ、1,000点以上、残り山4枚以上。宣言後はツモ切り |
| 鳴き | チーは上家からのみ。ポン・大明槓は他家から。暗槓可 |
| 槓 | 合計4回まで。槓ごとに嶺上牌・追加ドラ、山末尾を王牌へ補充 |
| 食い替え | 鳴いた牌と同じ種類、およびチーの筋食い替えを禁止 |
| 和了の優先 | ロン、ポン/槓、チーの順。複数ロンは放銃者から近い1人を優先 |
| 振聴 | 捨牌振聴、和了形になる牌の同巡の見逃し（役の有無を問わない）、リーチ後の見逃しでロン不可。ツモ可 |
| 流局 | テンパイ者とノーテン者間で合計3,000点を移動。本場加算 |
| 終局 | 規定の局数終了または飛び。残供託は首位へ。順位同点は起家に近い順 |

## 得点

喰い断あり、後付けあり、一翻縛りです。ドラ・裏ドラだけでは和了できません。
連風の雀頭は4符、七対子は25符、平和ツモは20符です。通常の符は10符単位で切り上げます。
切り上げ満貫なし、数え役満あり、役満複合あり、特殊待ちによるダブル役満なしです。
本場はロン300点、ツモ各100点。供託は和了者が受け取ります。

一盃口と二盃口、混全帯么九と純全帯么九などの排他的な役は二重に数えません。
複数の和了形がある場合は、和了牌の割当ても含めて得点最大の合法な形を選びます。
ロンで完成した刻子は、符と暗刻数の計算では明刻として扱います。

嶺上開花と海底摸月は複合しません。山がなくなった後の最後の打牌は、
嶺上牌の取得後であっても河底撈魚の対象にします。
振聴と河底の定義は [最高位戦の競技規定](https://saikouisen.com/pdf/saikouisen_regulation.pdf)
（第15条・第48条・振聴の条項）を参照しています。大会規定全体を採用するという意味ではありません。

## 初版で採用しない規則

赤ドラ、加槓と槍槓、リーチ後の槓、途中流局（四風連打・四槓散了など）、
流し満貫、天和・地和、包、ウマ・オカ、西入、オーラスの和了止めは扱いません。
未対応設定は黙って別ルールへ変換せず、宣言の検査で拒否します。

## 再現と検証

乱数種と操作列を固定して、同じ対局を再実行できます。各操作後に、
全136枚の所在、各種4枚、手牌の構造枚数、持点と供託の総和を検査します。
一局の巡目数には山の有限性が上限を与えます。連荘による対局の長期化を理由に
黙って試合を打ち切りません。端末アプリには、手動対局・実演・自動対局とも1試合10,000操作の実行上限を設けています。
見送りや次局への移行も1操作に数え、上限到達時は乱数種を表示して非0で終了します。通常の終局や検査成功には数えません。
この上限はアプリ側の実行制限で、対局ライブラリの麻雀規則ではありません。
