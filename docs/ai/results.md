# 固定対照評価の結果

事前に固定した条件で64東風戦を一度実行し、64試合すべてが操作上限内に正常終了しました。
Ukeireの候補設定は、この比較ではRandomより良い平均順位・平均持点になりました。
Greedyより強いこと、人間相手の強さ、他の条件での優越は検証していません。

## 対象と結果

[評価計画](evaluation.md)に従い、配牌の種1000〜1007と候補席0〜3を組み合わせ、
各群32試合を実行しました。候補以外の3席は、両群とも同じGreedy設定です。

| 項目 | 候補：Ukeire | 参照：Random |
|---|---:|---:|
| 予定試合数 | 32 | 32 |
| 正常終了 | 32 | 32 |
| 失敗・操作上限到達 | 0 | 0 |
| 1位 / 2位 / 3位 / 4位 | 6 / 9 / 10 / 7 | 0 / 0 / 10 / 22 |
| 平均順位 | 2.5625 | 3.6875 |
| 平均最終持点 | 24,650点 | 15,384.375点 |
| 候補席の和了局数合計 | 36 | 1 |
| 候補席の放銃局数合計 | 22 | 44 |
| 対局全体の操作数合計 | 27,515 | 33,721 |
| 候補席の判断回数合計 | 6,875 | 8,428 |
| 候補席の向聴計算回数合計 | 1,361,123 | 0 |
| 1試合の平均実行時間 | 約498.6ミリ秒 | 約35.7ミリ秒 |
| 1試合の最大実行時間 | 1,059ミリ秒 | 95ミリ秒 |

候補の具体値は、AI用の種20261123、向聴計算予算8192、読みの深さ2、防御重み4です。
参照は同じAI用の種で予算0・深さ0・防御重み0です。
他の3席はAI用の種0、Greedy、予算1024・深さ0・防御重み1です。
設定の完全な記録は[固定計画JSON](../../evaluations/ai-protocol.json)を参照してください。

同じ配牌の種・席で対応させた32組では、候補の順位が良い組が22、同順位が9、悪い組が1でした。
候補から参照を引いた平均順位差は−1.125、平均持点差は+9,265.625点です。
8個の種のそれぞれで4席を平均した持点差も、すべて正でした。

## 解釈できる範囲

- 32組は8個の配牌の種を4席で再利用したものです。32個の独立した配牌条件とは扱いません。
- 鳴きや打牌で牌の取得順が変わるため、両群が同じ局面列を経験した比較ではありません。
- Randomは合法和了・強制操作を優先し、それ以外を選ぶ弱い参照算法です。この比較だけでは、UkeireとGreedyの優劣を判定できません。候補の平均順位2.5625と平均持点24,650点から、Greedyに対する優越も主張しません。
- 和了・放銃は局数の合計です。分母となる総局数をこのCSVでは記録していないため、和了率・放銃率として表示しません。
- 実行時間は3人の相手も含む対局全体の値です。機器や同時実行処理の影響を含み、AI単体の速度比較や隔離された性能測定ではありません。
- 同じ相手3人・小さい種集合・東風戦という条件に限定された測定です。人間相手の段位、一般的な勝率、Strongプリセットの普遍的な優越は示していません。

評価後に算法・予算・評価用の種を調整せず、不利な結果も含めた全64行を保存しました。
実行中に対象ソースの変更がないことを、前後のSHA256で照合しています。
