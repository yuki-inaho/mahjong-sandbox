# AIの固定対照評価

## 事前に固定する条件

[ai-protocol.json](../../evaluations/ai-protocol.json)を、評価用の種を実行する前に保存します。
計画には具体的な設定、母数、種、席、操作上限、失敗の扱いとソース識別値を含めます。
識別値のFNV-1aは意図しない変更の検出用であり、暗号学的な完全性保証ではありません。
最終の実行証拠では別途SHA256も記録します。

| 条件 | 内容 |
|---|---|
| 乱数種 | 1000〜1007の8個 |
| 候補の席 | 各種で0〜3の全4席 |
| 候補群 | Ukeire、AI seed 20261123、予算8192、深さ2、防御重み4 |
| 参照群 | Random、AI seed 20261123、予算0、深さ0、防御重み0 |
| 他の3席 | Greedy、AI seed 0、予算1024、深さ0、防御重み1 |
| 母数 | 各群32試合、合計64試合 |
| 上限 | 1試合10,000操作。到達は失敗 |
| 完了条件 | 予定した全試合を結果へ残すこと。候補の優越は完了条件にしません |

種と席を対応させても、鳴きや打牌が変われば牌の取得順序も変わります。
二つの算法が同じ牌譜を経験した比較ではありません。
同じ8種を4席で使うため、64行を64個の独立した乱数条件とみなすこともしません。

## 実行

固定済みの計画がある状態で実行します。結果ファイルは存在しない新しい名前を指定してください。

```sh
cargo run -p suzume --release --bin suzume-ai-eval -- \
  --holdout --protocol evaluations/ai-protocol.json --output evaluations/ai-results.csv
```

実行前に、計画ファイルと実行形式に含まれる設定・ソース識別値が完全一致するかを検査します。
固定評価中に予算・算法・種・席を上書きする引数は拒否します。
既存の結果ファイルは上書きしません。

開発用の計測は別の種で行います。

```sh
cargo run -p suzume --release --bin suzume-ai-eval -- \
  --development --seed 0 --slot 0 --algorithm ukeire --budget 8192 --depth 2 --risk 4
```

開発モードでは1000〜1007を拒否します。調整前に行った開発用seed0の測定では、
Strong相当の1試合が1280操作・約0.6秒で完了しました。
これは実行時間の見積もりであり、強さの検証に評価用の種を使った記録ではありません。
ビルド時間、計測環境、後の処理変更により所要時間は変わります。

## 結果の列

CSVには群、配牌seed、候補席、算法、AI seed、具体的な設定、成否、順位、最終持点、
和了局数、放銃局数、操作数、候補の判断回数・向聴計算回数、実行時間、失敗理由を記録します。
和了局数・放銃局数は候補の席についての値です。実行時間は対局全体で、他の3人の判断も含みます。
順位は最終持点の高い順で、同点は席番号0〜3の小さい順です。

失敗時も行を保存し、正常終了と混ぜません。失敗した試合を除外した勝率を全体の勝率と表示しません。
順位・持点の要約には対象母数と失敗数を併記します。
時間制限・機器差・単一の対照・小さい種集合という制約を残し、他の対照や人間に対する強さへ一般化しません。

実施した64東風戦の成否・集計・解釈の限界は、[評価結果](results.md)に記録しています。
