# AIの種類と設定

麻雀スズメには `random`、`greedy`、`ukeire` の3種類のAIがあります。いずれも学習済みモデルを使わず、自分の手牌、公開情報、合法手から操作を選びます。他家の手牌や実際の山順序は判断に使いません。

## AIを選ぶ

| 算法 | 判断方法 | 制限 |
|---|---|---|
| `random` | 和了・次局・唯一の操作を優先し、ほかは合法手から均等に選択 | 牌効率は評価しません。同じ牌の別添字や、打牌とリーチも別の選択肢です |
| `greedy` | リーチを優先し、向聴数、リーチ者の河、牌のつながりを比較 | 有効牌の残枚数を使わないため、残り0枚の待ちを選ぶ場合があります |
| `ukeire` | 公開情報から数えた有効牌、防御重み、ドラを比較し、設定に応じて先読み | 相手の手牌推定や、正確な和了確率・期待得点の計算は行いません |

`beginner`、`standard`、`strong` は、算法と計算予算をまとめたプリセットです。勝率の順序を保証する名前ではありません。具体的な値は [共通設定](../api/configuration.md#ai設定の解決順序) を参照してください。
